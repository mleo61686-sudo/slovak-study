# Flunio 2.0 — фаза 5: єдиний навчальний маршрут

## Зміни

- На `/learning` з'явився **«Мій навчальний маршрут»** із чотирма типами практики: уроки → повторення слів → життєві місії → інтерактивні історії.
- Маршрут обчислюється на основі наявних результатів: звичайні уроки, SRS, місії та історії. Немає нової бази даних або нових збережених ключів.
- Для кожного виду вправ відображається доступність, короткий прогрес (лише де він вимірюється), а також безпечний перехід до найближчої рекомендованої вправи.
- Враховуються **Free / Premium**, рівень доступних уроків, актуальний мовний курс. Словацькі місії та історії не показуються на головній сторінці чеського/польського курсу та не рекомендуються в маршруті для інших мов.
- Після завершення звичайного уроку, місії або історії є кнопка **«Продовжити навчальний маршрут»**. Вона не з'являється під час незавершеного збереження місії/історії.
- Чотири стани («можна продовжити», «поки виконано», «немає даних», «поки недоступно») **не є оцінкою CEFR**. Порожня черга SRS — це тільки відсутність термінових повторень, а не доказ засвоєння всіх слів.
- Тексти маршруту й навігації доступні українською, російською та англійською, як і попередні етапи.

## Дизайн і збереження

Жоден файл CSS не змінювався; початкові **7 CSS-файлів** зіставлено з вихідним архівом побайтово. Використовуються чинні токени `flunio-card`, `theme-inner-card`, `theme-text` тощо. Обидві теми збережено.

Фаза 5 не змінює API прогресу, схему Prisma, XP, рейтинг або вже збережені результати. `main` не змінюється: патч застосовується вручну користувачем у робочій гілці `courses-ui`.

## Архів

**`Flunio-v2-phase2-through-phase5-changed-files.zip` — накопичувальний патч фаз 2–5, призначений для проєкту, де вже встановлена фаза 1.** Не потрібно встановлювати фази 2, 3, 4 окремо. НЕ розпаковуй його поверх чистого `main`: без фази 1 оновлення неповне.

Перед майбутнім встановленням зроби контрольний коміт/резервну гілку `courses-ui`, перевір чистоту робочої директорії і тільки потім розпакуй патч із заміною відповідних файлів.

Тести після встановлення:

```powershell
npm install
npm run test:lesson-v2
npm run test:missions-v2
npm run test:personal-plan-v2
npm run test:stories-v2
npm run test:journey-v2
npm run build
```

## Перевірено в середовищі підготовки

- Автотести фаз 1–5 пройшли.
- Строга перевірка типів **чистої логіки** `planner.ts` і `journey.ts` успішна.
- Синтаксичний розбір змінених TS/TSX-файлів успішний.
- Сім початкових файлів CSS не змінені.
- **Повна збірка Next.js та браузерна перевірка фаз 2–5 у цьому середовищі НЕ завершені** через неповні залежності; локальний `npm run build` у VS Code потрібен до деплою.
- Контент залишається пілотним: 3 місії, 3 історії. Не заявляти, що це повний курс для всіх рівнів або сертифікація CEFR.
