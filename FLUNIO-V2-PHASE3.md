# Flunio 2.0 — Фаза 3: персональний план і навчальний профіль

## Що додано

На сторінці `/learning` з’являються **«Мій план на сьогодні»** та **«Мій навчальний профіль»**. Оновлення працює у світлій і темній темах за вже наявними CSS-класами; самі CSS-файли, перемикач тем, токени кольорів **не змінювались**.

### План
- Першим пріоритетом — до 30 слів SRS, для яких настав час повторення; для авторизованих користувачів використовуються чинні SRS-дані. Ліміти, прогрес і XP не перезаписуються.
- Наступний крок — короткий повтор уроку, який завершено з результатом нижче 80%, **якщо цей урок раніше не був засвоєний**; або перший доступний непройдений урок.
- Для словацького курсу — найближча відповідна життєва місія. A2/B1 місії не пропонуються до досягнення відповідного етапу, а без Premium не пропонуються закриті місії.
- План будується з актуальних даних — це **рекомендації**, а не календар чи обов'язковий розклад. Час на завдання орієнтовний.
- Гості бачать план з уроками й безкоштовною словацькою місією. SRS-план потребує входу, оскільки чинний SRS-тренажер прив’язаний до акаунта.

### Навчальний профіль
- Пройдені уроки, окремо позначені як засвоєні уроки, середня точність останніх спроб (якщо результат є), SRS-картки та пройдені словацькі місії.
- Усне мовлення й аудіювання **не отримують вигаданих оцінок**: позначено «окремо не оцінюється».
- Дані не створюють «сертифікований рівень CEFR», це статистика навчальних вправ.
- Чеська/польська не показують словацькі місії або їхню статистику.

### Безпека прогресу
- Загальна синхронізація `/api/progress` тепер залишає `__missions` під серверним контролем. Старі локальні копії не можуть стерти чи зменшити оцінки, отримані через `/api/learning/missions`.
- Не додається схема БД, localStorage-ключі, фонова автоматизація, мутації XP, нова система доступу чи зовнішній AI-сервіс.

## Встановлення: важливо

**Архів `Flunio-v2-phase2-and-phase3-changed-files.zip` накопичувальний від фази 1.** Він включає всі файли фаз 2 і 3. Якщо ти вже встановив фазу 2, архів також підходить: файли фази 2 будуть оновлені, а фази 3 — додані.

Зроби резервний коміт або гілку з поточного стану `courses-ui`. Розпакуй файли архіву **в корінь репозиторію** з заміною у гілці `courses-ui`. Не замінюй `main` і не видаляй `public`, `.env.local`, `node_modules` тощо.

## Технічна перевірка

```powershell
npm run test:lesson-v2
npm run test:missions-v2
npm run test:personal-plan-v2
npm run build
```

У цьому середовищі ізольовані автотести пройшли, а синтаксис змінених TS/TSX перевірено. **Повну збірку Next.js і візуальну перевірку в браузері тут не виконано** — модулі `node_modules` у робочій копії неповні. Перевірка має пройти на твоєму ПК перед публікацією.

## Ще не реалізовано

Це ще **не фінальна Flunio 2.0**: заплановані більша бібліотека місій, інтерактивні історії, якісні B1–B2 аудіо та валідований модуль усної практики. Профіль окремих мовних навичок потребуватиме надійних оцінюваних активностей, а не припущень.
