# Flunio 2.0 — фаза 4: Interactive Stories

## Що реалізовано

- Новий розділ `/learning/stories` і сторінки `/learning/stories/[slug]`.
- Три **авторські сценарії словацькою**:
  - **A1: Загублені ключі** — безкоштовно;
  - **B1: Несподівана зміна на роботі** — Premium;
  - **B2: Збори мешканців щодо ремонту** — Premium.
- У кожному: словацькі репліки з перекладом **українською / російською / англійською**, словничок у контексті, щонайменше два можливі шляхи, три запитання на розуміння тексту та пояснення відповідей.
- Словацьке озвучення через **TTS браузера** (лише якщо на пристрої є відповідний голос). Можна спершу прослухати, а потім відкрити текст. Це **не професійний запис** і **не валідація рівня аудіювання**.
- Відновлення незакінченої історії після оновлення сторінки (sessionStorage в поточному браузері).
- Для гостей статистика зберігається локально; для авторизованих результати записуються через окремий API з **серверною перевіркою повноти проходження й правильності відповідей**. Результати — кількість проходжень, останній/найкращий %, позначка засвоєння від 80%.
- Прогрес історій зберігається окремо в `lessonsProgress.byCourse.sk.__stories`, **без міграції БД, без XP та змін старих уроків**.
- На сторінку `/learning` додано посилання на розділ історій.
- Персональний план і навчальний профіль фази 3 враховують результати історій; Premium та розподіл за курсами перевіряються.
- Загальна синхронізація `/api/progress` не може перезаписати `__stories` застарілими даними браузера.

## Дизайн

**Світла й темна теми не змінені.** Немає нових/змінених CSS-файлів, темних хардкодів чи зміни перемикача тем. Новий UI використовує чинні `flunio-card`, `theme-inner-card`, `theme-text`, `theme-primary-button` та інші наявні класи.

## Інсталяція (коли вирішимо завершити розробку й тестувати)

**`Flunio-v2-phase2-through-phase4-changed-files.zip` накопичувальний після фази 1**: містить зміни фаз 2, 3, 4. **НЕ встановлюй** окремі архіви фаз 2 і 3 перед ним. Проєкт уже повинен містити фазу 1, яку встановлено раніше.

Створи коміт або резервну гілку **на `courses-ui`**, після чого розпакуй ZIP у корінь репозиторію з заміною файлів. Не чіпай `main`, `.env.local`, `public`, `node_modules`.

Перевірки після встановлення:

```powershell
npm install
npm run test:lesson-v2
npm run test:missions-v2
npm run test:personal-plan-v2
npm run test:stories-v2
npm run build
```

## Проведені перевірки та обмеження

- Автотести контенту перевірили всі три історії й обидві сюжетні гілки, правильне оцінювання (3 запитання на кожен маршрут) та відхилення зайвих, недійсних або неповних відповідей.
- Тести API перевірили авторизацію, Premium, злиття спроб і відсутність втрати результатів уроків, місій та інших мовних курсів.
- Старі тести фаз 1–3 також пройшли.
- Додано регресійний тест захисту `__stories` при синхронізації з браузера.
- **Повну збірку Next.js і ручне браузерне тестування фази 4 у цьому середовищі не проводили**, бо локальні `node_modules` неповні. Перш ніж публікувати, потрібно виконати перевірки у VS Code.

## Не входить у фазу 4

- Немає записаного студійного аудіо B1–B2.
- Немає автоматичного визначення рівня говоріння, автоматичного оцінювання вимови чи сертифікації CEFR.
- Немає необмеженої AI-генерації історій: контент навмисно перевірений і детермінований.
- Flunio 2.0 не завершений повністю: попереду масштабування контенту, UX-тестування та фінальне інтеграційне тестування.
