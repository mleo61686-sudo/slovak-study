# FLUNIO ARCADE V2 — інтегрований ZIP-патч

**Дата:** 11.11.2026  
**Основа:** Flunio на `main` після встановлення `flunio-daily-patch.zip` (версія Daily v1).  
**Формат:** архів містить лише нові та змінені вихідні файли, не весь проєкт.

## Реалізація

- Flunio Daily перетворено на Flunio Arcade: **12 раундів за сесію, 6 ігрових механік**, три рівні складності (A0–A1, A2–B1, B2–C1).
- Режими: розпізнавання значення, збирання речення з плиток, вибір пропущеного слова, правда/неправда, зіставлення трьох пар, введення слова з клавіатури.
- Словацька/чеська/польська гра відображає всі назви, пояснення та відповіді **мовою відповідного курсу**. Головний `/daily` підхоплює `slovakStudy.activeCourse` — той самий вибір, що й решта Flunio. Прямі SEO-сторінки використовують конкретну мову незалежно від курсу.
- Нові авторські набори для початкового й повсякденного рівня плюс попередній відредагований банк висловів для складного рівня. Усього **210 висловів і 81 ситуація з пропущеним словом** на три мови.
- Детермінована ротація завдань за датою, курсом і рівнем. Повторювати можна; зберігається найкращий бал за день/рівень. **Серія днів рахується лише один раз на день**, хоч би скільки рівнів пройдено.
- Незавершений сеанс зберігається в `localStorage` і відновлюється, пояснення відповідей показуються у грі. Прогрес v1 враховується для серії днів, але колишні три питання не блокують проходження нових 12 раундів.
- Ігрове оформлення зі світлою/темною темою Flunio, адаптивними плитками, ареною, анімаціями зі зменшенням руху для `prefers-reduced-motion`.
- На головній **прибрано дублюючий банер Daily**; інструмент інтегровано як окрему дев’яту іконку у «Швидкий доступ» поруч із курсами, тренажером, словником тощо. Прибрано зайвий пункт Daily із верхнього меню.
- SEO: `/daily`, `/daily/slovak`, `/daily/czech`, `/daily/polish` з окремими метаданими, локалізованими текстами і записами в sitemap. Контекстне посилання з `/polish-vocabulary` веде до польської гри.
- **Не чіпає** чинні уроки, Premium, Prisma, AdSense, `public`, `.env.local`, глобальні стилі й рекламу; не додає залежностей, API-витрат або міграцій БД.

## Встановлення

Для твого звичного способу використай PowerShell-команду з повідомлення ChatGPT: вона відкриє вікно вибору файлу, після чого накладе ZIP у `D:\slovak-study\slovak-study` на гілку `main`. Потрібна чиста робоча директорія Git, перед заміною файлів скрипт створить резервні копії.

**Важливо:** цей патч накладається **після v1**. Не запускай копіювання, якщо в тебе незакінчене редагування змінених файлів — спочатку зроби commit.

### Перевірки після встановлення

```powershell
node tests/daily-arcade-v2-smoke.cjs
node tests/daily-challenge-smoke.cjs
npm run build
npm run dev
```

У браузері відкрий `http://localhost:3000/daily`, потім усі три SEO-маршрути. Протестуй послідовне проходження 12 раундів, повторну гру, перезавантаження під час сесії, зміни курсів, світлу/темну тему й мобільну ширину. **Не роби `git push` до успішного локального `npm run build` та огляду сторінок.**

## Перевірки в середовищі підготовки

- `tests/daily-arcade-v2-smoke.cjs`: **3 285 змодельованих сесій** (365 дат × 3 мови × 3 рівні); перевірені ротація, унікальність значень, відповіді, парність, перемішування плиток, відновлення сесії, підрахунок балів, серія днів і SEO-посилання. **Пройдено.**
- TypeScript `--strict` для ігрового ядра, синтаксичний розбір змінених TS/TSX-файлів: **пройдено**.
- Локальний `next build` у середовищі підготовки **не запускався**: в архіві джерел немає `node_modules` і великої папки `public`, а офлайн `npm ci` не має всіх пакетів. У тебе локально ці файли є, тому обов’язково перевір `npm run build`.
