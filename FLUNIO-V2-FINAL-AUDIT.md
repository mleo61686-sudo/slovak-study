# Flunio 2.0 — контрольний аудит інтеграції, 2026-11-02

## Що входить до накопичувального оновлення

1. **Фаза 1:** адаптивніші словникові уроки (20–24 основні вправи для 10 слів, де доступні перевірені контексти), повторення помилок, окреме оцінювання засвоєння й додавання слів у поточний SRS.
2. **Фаза 2:** три перевірені ситуаційні місії: магазин, запис до лікаря, проблема на роботі; голосове введення залежить від можливостей браузера, а вільні відповіді не оцінюються автоматично.
3. **Фаза 3:** персональний план і профіль виміряних навичок; захист серверних результатів місій/історій від перезапису загальною синхронізацією прогресу.
4. **Фаза 4:** три інтерактивні історії з розгалуженнями, перевіркою розуміння та необов'язковим браузерним озвученням словацькою.
5. **Фаза 5:** спільний навчальний маршрут і повернення до нього після завершення вправ.
6. **Фінальні виправлення:** ізоляція чернеток місій за користувачами; повторне збереження результатів місій і історій після помилки мережі; окремий регресійний тест `test:final-audit-v2`.

## Що збережено

- Вихідні сім CSS-файлів байт-в-байт не змінювалися (світла й темна теми).
- Схема Prisma, чинні системи XP, рейтингу, Premium та звичайних уроків не замінені новими.
- Нові місії та історії наразі стосуються тільки словацької; чеський і польський курси не змішуються з ними.
- Архів — накладне оновлення файлів, він **не виконує команди Git** і не змінює `main` автоматично. Слід застосовувати його тільки в `courses-ui` після резервної копії.

## Встановлення пізніше (на Windows/VS Code)

1. Переконатися, що активна гілка `courses-ui` і робоча директорія чиста (`git branch --show-current`, `git status --short`).
2. Зробити резервну гілку або коміт.
3. Розпакувати **один** `Flunio-v2-complete-phase1-5-audited.zip` у корінь проєкту з заміною файлів. У ZIP є всі фази 1–5, тому проміжні архіви не потрібні. Не витягувати в окрему вкладену папку.
4. Запустити:

```powershell
npm install
npm run test:lesson-v2
npm run test:missions-v2
npm run test:personal-plan-v2
npm run test:stories-v2
npm run test:journey-v2
npm run test:final-audit-v2
npm run build
```

5. Після успішної збірки провести вручну один повний навчальний сценарій для Free та Premium, перевірити збереження прогресу й світлу/темну теми. Після цього — коміт та `git push origin courses-ui`.

**Навчальний контент — пілотний:** 3 місії та 3 історії, а не повний курс із підтвердженням рівня CEFR. Браузерне TTS не гарантує наявність словацького голосу.
