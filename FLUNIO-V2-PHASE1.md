# Flunio 2.0 — перший етап модернізації уроків

## Що змінилося

- **Новий сценарій уроку**: усі слова проходять впізнавання, потім пригадування (різна складність для A0–B2), а до 4 додаткових завдань використовують лише наявні перевірені речення. Перевірка наявності речень здійснюється на сервері, щоб не тягнути всі словники в початковий клієнтський пакет. При 10 словах урок містить зазвичай 20–24 основні завдання замість 70.
- **Повторення помилок**: після основного маршруту користувач отримує один додатковий раунд лише на словах, де помилявся. Це тренування не підвищує бал за першу спробу.
- **Засвоєння окремо від завершення**: сервер записує `mastered` (поріг ≥80%) і `lastResultPercent` у вже наявний JSON `lessonsProgress`; старі дані, механізм розблокування уроків, XP та Premium не змінюються. Раніше високі результати теж визнаються під час наступного запису.
- **Зв’язок уроку з SRS**: на сторінці завершення є кнопка «Додати слова до повторення». Вона додає тільки нові слова, враховує ліміт 30 на день і не перезаписує наявні SRS-картки. Працює через наявні ключі та події синхронізації.
- **Речення без небезпечних автоматичних шаблонів**: новий маршрут не запускає вправи зі складання речень без створеного в контенті прикладу (наприклад, не створює `To je ísť.`).
- Український, російський та англійський інтерфейси нових елементів.

## Чого не змінювали

- Обидві теми Flunio: світлу та темну; файли CSS, змінні кольорів, перемикачі.
- Базу даних і Prisma-міграції, авторизацію, платіжну частину, структуру SRS та поточні збережені прогреси.
- Чеські та польські уроки залишаються доступними й використовують цю саму базову логіку.

## Перевірка на своєму ПК

У терміналі з кореня проєкту:

```powershell
npm install
npm run test:lesson-v2
npm run build
npm run dev
```

У браузері перевірити A0-1, A1-1 (за наявності Premium), результат 80%+, допрактикування помилок, кнопку додавання до SRS, синхронізацію ПК ↔ мобільний і перемикання світлої/темної теми.

**Увага:** в наданому архіві не було папки `public`, `.env` та `node_modules`. У повному оновленому архіві їх теж немає. Не видаляйте ці папки/файли зі свого робочого проєкту. Для оновлення безпечніше використати архів лише зі зміненими файлами, скопіювавши їх із заміною у свій проєкт.

**Статус в цьому середовищі:** тест логіки `lesson-v2-smoke.cjs` пройшов, перевірка синтаксису змінених TS/TSX — пройшла. Повна збірка Next.js не виконана: встановлення всіх залежностей тут не завершилося. Це не підтверджений production build. Перед публікацією виконайте `npm run build` локально.
