# Flunio Daily — патч №1 (11.11.2026)

## Що реалізовано
- Новий розділ `/daily`: 3 щоденні питання (словацька, чеська, польська), 30 відредагованих висловів на кожну мову, різний порядок відповідей, приклади в контексті й переклади пояснень українською, російською та англійською.
- Без Premium та авторизації. Результат кожного дня, локальна серія днів, найкраща серія та загальна кількість завершень зберігаються в `localStorage` окремо для кожної мови. Немає API-запитів або платних AI викликів.
- Акуратне вбудовування у головну сторінку, адаптивне меню, футер та sitemap. Наявні теми `theme-flunio` та `theme-simple` не змінені.
- Контекстне посилання з `/polish-vocabulary` (найкраща сторінка за даними Search Console).
- Кастомна подія Vercel Analytics `daily_challenge_completed` з двома несекретними параметрами: `course` і `score` (доступність перегляду подій залежить від вашого тарифу Analytics).
- Smoke-тест `tests/daily-challenge-smoke.cjs` і необов'язковий PowerShell-скрипт `scripts/ensure-ads-txt.ps1`.

## Як застосувати ZIP
**Важливо:** гілка `courses-ui` або інша робоча гілка має бути закомічена до накладання патчу. Архів містить тільки додані або змінені файли, а не весь проєкт.

1. У VS Code відкрий термінал PowerShell в корені Flunio.
2. Переконайся, що маєш резервну копію / git commit поточного стану.
3. Виконай:

```powershell
Expand-Archive -LiteralPath "$([Environment]::GetFolderPath('Desktop'))\flunio-daily-patch.zip" -DestinationPath . -Force
npm run build
node tests/daily-challenge-smoke.cjs
```

Якщо файл завантажено не на робочий стіл, заміни шлях до ZIP. `node_modules` потрібна для повної збірки (якщо немає — виконай `npm ci`). Тест використовує наявний devDependency `typescript`.

Після локальної перевірки відкрий `/daily`, перемкни темну/світлу теми, обери всі три мови, перевір мобільне меню. Стара логіка уроків і Premium не змінювалася.

## AdSense: що вже є та що треба зробити

**У `app/layout.tsx` із вихідного архіву вже існували** `google-adsense-account` та глобальне завантаження Auto Ads зі значенням `ca-pub-1760161415033749`. Цей патч їх не дублює і не додає рекламу між варіантами відповідей.

1. В AdSense → Sites перевір, чи `flunio.com` має статус **Ready** (готовий), а в Ads → By site увімкнені Auto Ads, якщо їх хочеш.
2. В AdSense → Account → Settings → Account information перевір, що publisher ID справді **pub-1760161415033749**. Якщо він інший, спочатку виправ його у `app/layout.tsx` і в скрипті нижче.
3. Перевір, чи існує `https://flunio.com/ads.txt`. Якщо там немає потрібного рядка, виконай у корені проєкту (скрипт зберігає інші наявні рядки):

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\ensure-ads-txt.ps1
```

Після деплою відкрий `https://flunio.com/ads.txt`. Правильний рядок для ID із архіву:
`google.com, pub-1760161415033749, DIRECT, f08c47fec0942fa0`

4. **Для EEA/UK/CH** налаштуй Google-certified CMP (Consent Management Platform), сумісну з IAB TCF, у AdSense Privacy & messaging (або іншу сертифіковану CMP). Перевір політику конфіденційності та фактичні налаштування згоди; не вважай завантаження рекламного скрипта ознакою виконання вимог.
5. Покази Google Search Console — це **покази в пошуку**, а не перегляди сторінок чи рекламні покази. Для фінансової цілі дивись AdSense Page views, Page RPM, estimated earnings та окремо витрати і Premium.

**Ні на локальній збірці, ні за цим архівом не можна підтвердити**, що сайт схвалений AdSense та рекламу вже показано; це видно у твоєму кабінеті.

Офіційні довідки:
- https://support.google.com/adsense/answer/12171612
- https://support.google.com/adsense/answer/12170222
- https://support.google.com/adsense/answer/13554116

## Межі поточної реалізації

- Це **перша версія**: банк із 30 висловів на мову, щоденна ротація (вирази періодично повторюються для закріплення). Для довгострокового утримання додавати нові вирази потрібно регулярно; банк сам не поповнюється.
- Локальний прогрес не синхронізується між пристроями, а очищення даних браузера його видаляє.
- Не створені тематичні статті/новини, поштові нагадування та серверний рейтинг: це наступні окремі задачі після оцінки першої версії.
- У цьому середовищі виконано синтаксичний розбір TS/TSX та детермінований smoke-тест, але не повний Next.js production build (архів свідомо не містив `node_modules`). Тому `npm run build` на твоєму ПК — обов'язкова перевірка.
